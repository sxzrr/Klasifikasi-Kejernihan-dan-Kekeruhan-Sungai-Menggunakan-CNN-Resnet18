🎯 ROOT CAUSES (Mengapa Overfitting Terjadi?)
═══════════════════════════════════════════════════════════════════════════════

    1️⃣  DATASET KECIL
        └─ 143 training images untuk fine-tune ResNet18 (18 layers)
           ↓
           Model mudah memorize patterns daripada generalize
    
    2️⃣  STAGE 2 TERLALU AGRESIF
        ├─ 20 epochs terlalu panjang untuk small dataset
        ├─ Epoch 15+: Model sudah overfitting
        └─ Learning rate 0.0001 masih "terlalu cepat" untuk fine-tune
    
    3️⃣  REGULARISASI KURANG
        ├─ Dropout 0.5 hanya di 1 layer
        ├─ Tanpa weight decay (L2 regularization)
        └─ Tanpa early stopping (berhenti kapan?)
    
    4️⃣  TANPA DATA AUGMENTATION
        ├─ Model cuma lihat 143 images original (tanpa variasi)
        ├─ Tidak ada rotation, flip, brightness variation
        └─ Real-world images berbeda → model fail generalize
